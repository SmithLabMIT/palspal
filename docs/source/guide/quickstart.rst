Quickstart
==========

PALSpal is composed of two main modules:

``palspal.inputter``, which manipulates data that is to be input into PALSfit3
(e.g., the ``.rfc`` and ``.pfc`` files), and ``palspal.outputter``, which
manipulates data that is output from PALSfit3 (e.g., the ``.out`` files).

``palspal.inputter``
--------------------

Within ``palspal.inputter``, there are two main classes: ``RFCFile`` and
``PFCFile``, which are used to read, manipulate, and run ``.rfc`` and ``.pfc``
files, respectively.

To start using ``palspal.inputter``, it must be imported:

.. code-block:: python

   from palspal import inputter

An existing ``.pfc`` file can be read in by creating an instance of the
``PFCFile`` class:

.. code-block:: python

   input_pfc = inputter.PFCFile("path/to/file.pfc")

Alternatively, a new ``.pfc`` file can be created and then read in:

.. code-block:: python

   inputter.PFCFile.write("path/to/file.pfc")
   input_pfc = inputter.PFCFile("path/to/file.pfc")

Data within the ``.pfc`` file can be manipulated by using the ``PFCFile``
class methods. For example, to change the timezero value:

.. code-block:: python

   input_pfc.timezero = 300

All manipulations are performed in the same units as used in PALSfit3. For
example, the timezero is in channels. All manipulations that can be performed
can be found in :ref:`manipulating-input-files`.

After making any manipulations (or none) to the ``.pfc`` file, it can be run
using the PALSfit3 backend executable:

.. code-block:: python

   input_pfc.run(
       exe_path="path/to/pos19.exe",
       out_file="path/to/write/file.out"
   )

Any manipulations made to the ``.pfc`` file can be saved to a new ``.pfc``
file:

.. code-block:: python

   input_pfc.write("path/to/new_file.pfc")

While writing the file is not required, it can be helpful for future runs or
for loading the file into PALSfit3 to use the graphical user interface.

All of these same commands can be used with a ``.rfc`` file by using the
``RFCFile`` class instead of the ``PFCFile`` class and swapping the location
of ``pos19.exe`` with the location of ``res19.exe``.

``pos19.exe`` and ``res19.exe`` can be downloaded from the
`PALSfit3 website <https://palsfit.dk/Download>`_.

``palspal.outputter``
---------------------

Within ``palspal.outputter``, there are two main classes: ``RFCOutFile`` and
``PFCOutFile``, which are used to read ``.out`` files generated by PALSfit3
from ``.rfc`` and ``.pfc`` files, respectively.

To start using ``palspal.outputter``, it must be imported:

.. code-block:: python

   from palspal import outputter

An existing ``.out`` file can be read in by creating an instance of the
``PFCOutFile`` class:

.. code-block:: python

   output_pfc = outputter.PFCOutFile("path/to/file.out")

Data within the ``.out`` file can be retrieved by using the ``PFCOutFile``
class methods. For example, to get the timezero value and its standard
deviation:

.. code-block:: python

   timezero = output_pfc.timezero
   timezero_std = output_pfc.timezero_std

All retrievals are performed in the same units as used in PALSfit3. For
example, the timezero and its standard deviation are in channels. All
retrievals that can be performed can be found in
:ref:`retrieving-output-files`.

All of these same commands can be used with a ``.out`` file created from a
``.rfc`` file by using the ``RFCOutFile`` class instead of the ``PFCOutFile``
class.
